# Causal Inference Methods for Observational Data

This repository contains materials for a **1-day applied workshop** on **causal inference methods for observational data**. The workshop introduces participants to the foundations of causal inference, key tools for reasoning about causality, and applied examples of estimation strategies.

## Schedule & Topics

### 1. Potential Outcomes Framework
- The Experimental Ideal
- Counterfactual reasoning
- The Fundamental Problem of Causal Inference

### 2. Directed Acyclic Graphs (DAGs)
- Confounding
- Selection Bias

### 3. Causal Identification in Observational Studies
- Methods for estimating causal effects
- Assumptions required for causal identification

### 4. Applied Example: Difference-in-Differences (DiD)
- Estimating the Average Treatment Effect on the Treated (ATT)
- Interpreting results in practice

## Learning Goals
By the end of the workshop, participants will be able to:
- Distinguish between **correlation** and **causation**.
- Understand the **potential outcomes framework** and the challenges of counterfactual reasoning.
- Use **DAGs** to visualize causal assumptions and sources of bias.
- Apply common methods for causal identification in observational settings.
- Estimate and interpret treatment effects with **difference-in-differences (DiD)**.
